# Weather App

A responsive and user-friendly weather application that allows users to get real-time weather information based on their location or any city around the world.

## Demo

Check out the live version of the app: [Weather App Demo](https://weather-app-yani.netlify.app)

## Features

- **Search for weather by city name**: Enter any city's name and get current weather information.
- **Real-time data**: Fetch weather updates in real-time from a reliable weather API.
- **Responsive Design**: The app works on all devices (mobile, tablet, and desktop).
- **Weather details**: View temperature, humidity, wind speed, weather conditions, and more.
- **Error handling**: Displays meaningful error messages when data is unavailable or input is invalid.

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript (ES6+), React (if applicable)
- **API**: OpenWeatherMap API for weather data
- **Deployment**: Netlify for hosting
